Un kanban board in stile Trello costruito con **HTML, CSS e JavaScript puri**. Nessuna dipendenza esterna.

## ✨ Funzionalità

- **Drag & drop** fluido tra le liste
- **CRUD completo** di liste e card
- **Priorità** (bassa, media, alta) con barra colorata
- **Checklist** con barra di progresso
- **Tag personalizzati** per ogni card
- **Scadenze** con avviso per quelle imminenti o scadute
- **Ricerca live** su titolo, descrizione e tag
- **Filtro per priorità**
- **Statistiche board** (card totali, completate, in scadenza…)
- **Tema chiaro/scuro**
- **Salvataggio automatico** in localStorage
- **Nome board modificabile**
- **Scorciatoie tastiera** (Ctrl+K, Ctrl+N, Esc)

## 🛠 Tecnologie

- HTML5
- CSS3 (Grid, Flexbox, animazioni, drag & drop nativo)
- JavaScript (ES6+, Drag & Drop API, LocalStorage, MutationObserver)

## 📖 Scorciatoie

| Tasto | Azione |
|---|---|
| `Ctrl + K` | Focus sulla ricerca |
| `Ctrl + N` | Nuova lista |
| `Esc` | Chiudi modal / menu |
